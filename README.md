## What KMSAuto does
- Installs the public GVLK key for your Windows or Office edition
- Points the licensing client at a local KMS host
- Gets a 180-day volume license that renews about every 7 days

## Supported editions
- Windows 11 / 10 Pro, Education, Enterprise, LTSC
- Office 2016–2024 volume editions
- Not supported: Windows Home and Office retail or Microsoft 365

## Before you run any file
- Download it from one source only and compare the SHA-256 hash
- Scan it with a multi-engine scanner
- Avoid "Ultimate" repacks, password-protected archives and survey sites

## Common errors
- 0xC004F074: no KMS host reachable
- 0x80070005: access denied (run as administrator)
